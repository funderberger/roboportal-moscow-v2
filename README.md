# Робопортал Москвы — вариант 2

Прототип портала: каталог роботов, площадки для испытаний, программы
поддержки, аналитика и личный кабинет. Одна страница, без сборки и
зависимостей — `index.html` открывается как есть.

Живая версия: https://funderberger.github.io/roboportal-moscow-v2/

## Что внутри

- **Главная** — что можно поручить роботу, поддержка под задачи, площадки
  для испытаний, роботы в реальной работе
- **Роботы** — 113 решений с фотографиями, фильтрами и карточками моделей
- **Испытания** — среды и площадки, программа испытаний
- **Займы и гранты** — программы городской поддержки
- **Аналитика** — исследования
- **Личный кабинет** (`#account`) — профиль, роль на портале, заявки,
  роботы, поддержка. Данные кабинета хранятся в localStorage браузера

## Разработка

Отдельного сервера не нужно, но из-за относительных путей к видео и
картинкам страницу лучше открывать не файлом, а по http:

```
python3 -m http.server 8000
```

Затем http://localhost:8000/
